## About

**theBlocks!** is a block puzzle game. Place pieces onto an **8×8 board**, fill rows and columns to clear them, and chain combos to rack up bigger scores. It's the same gameplay as **Block Blast!** but without any trackers, ads, in-app purchases or privacy concerns.

It has a clean **Material You** design which adapts to the color of your phone's wallpaper (on Android 12 and newer) and has support for both light and dark mode.

## Download

1. Open the [**Releases page**](https://github.com/theStudio-official/theBlocks/releases/tag/v1.0).
2. Download the latest `.apk` file.
3. Open it, allow installations from your file manager/browser and install it.

> Only **Android** is currently supported.
